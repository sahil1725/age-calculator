# Chronos - Precision Age & Chronological Life Calculator

A sophisticated, edge-case-resilient chronological age calculation engine engineered with JavaScript (ES6+), CSS Glassmorphism, and responsive design.

## ?? Key Features
- **Accurate Calendar Calculations:** Computes exact age in **Years, Months, and Days** with dynamic month-end borrowing (28, 29, 30, or 31 days) and full leap year handling.
- **Strict Client-Side Validation:** Automatically blocks future dates and malformed inputs with instant DOM feedback.
- **Next Birthday Countdown:** Real-time countdown tracking days remaining until the user's upcoming birthday.
- **Cumulative Lifetime Metrics:** Computes total lifetime statistics:
  - Total days lived
  - Total weeks
  - Total hours lived
  - Total minutes lived
- **Astrological & Calendar Telemetry:** Determines the exact day of the week the user was born and their Astrological Zodiac sign with emoji glyphs.
- **Fluid UI Design:** Built with modern CSS Glassmorphism, dark gradient backdrop, and responsive layouts.
